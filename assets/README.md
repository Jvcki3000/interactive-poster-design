# assets — 素材库

存放海报的视觉素材。**由图像生成模型产出，或由用户提供**，Engine 只负责引用与加工。

## 目录
| 路径 | 用途 |
| --- | --- |
| `images/` | 背景图 / 人物 / 产品图（AI 生成或用户上传） |
| `fonts/` | 字体文件（注意版权与授权） |
| `textures/` | 纹理 / 颗粒 / 噪点 / 纸张质感 |

## 约定
- 大文件不入库：优先引用 URL，或放入 `.gitignore` 的 `dist/` / `out/`
- AI 生成素材时记录 prompt 到同目录 `*.prompt.txt`，便于复现与迭代
